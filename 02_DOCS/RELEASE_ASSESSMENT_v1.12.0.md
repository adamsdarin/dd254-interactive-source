# DD254 Interactive v1.12.0 — completion shortcuts

8 September 2026. Internal Tool v2.124. Single HTML file; existing browser storage.

## Changes and user benefit

| Change | Concrete reduction in work | Safeguard |
| --- | --- | --- |
| Copy Item 6/7 into Item 8 | One action copies up to five entered site fields | Does not overwrite a matching site or infer verification |
| Go to field and inline findings | Opens the relevant step and focuses the entry | Uses existing findings; no invented rule set |
| Combined Item 13 insertion | One preview/confirmation for multiple missing selected sections | Preserves populated sections; cancel and stale-preview guards |
| Find unfinished prompts | Selects the next recognized bracketed prompt in the editor | Advisory only; does not validate contract authority |
| Optional supporting records | Collapsed below the source log; removes its additional issuance dialog | Stored evidence and existing approval holds retained |

## Verification and limits

The regression suite covers copying, duplicate/manual-edit preservation, read-only
behavior, direct navigation, inline message clearing, combined insertion,
cancellation, stale previews and exact prompt selection. Native Chrome exercises
the actual controls in both official and demo files. Existing export, backup,
approval and issuance coverage remains. See the recorded test log and BUILD_FACTS.md
for results and hashes of the shipped files.

No new legal rule, classification decision, authority determination, service,
account or storage medium is introduced. The existing template text still needs
review. Prompt detection and field routing do not cover every possible error.
No measured claim about total completion time or real-world error rate is made.
The earlier v1.11.0 review records remain available and backup-compatible.
